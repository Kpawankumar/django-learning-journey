========================================
DJANGO SETUP & COMMANDS
========================================

----------------------------------------
1. ACTIVATE VIRTUAL ENVIRONMENT
----------------------------------------

Using Conda:
    conda activate venv

Verify Django Installation:
    python

Inside Python shell:
    import django
    django.__version__

Exit Python shell:
    quit()

----------------------------------------
2. CREATE A DJANGO PROJECT
----------------------------------------

Create a new Django project:
    django-admin startproject project_name

Navigate to the project directory:
    cd project_name

Project Structure:
    project_name/
    │
    ├── manage.py
    ├── project_name/
    │   ├── __init__.py
    │   ├── settings.py
    │   ├── urls.py
    │   ├── asgi.py
    │   └── wsgi.py

----------------------------------------
3. CREATE A DJANGO APP
----------------------------------------

Create a new app:
    python manage.py startapp app_name

App Structure:
    app_name/
    │
    ├── migrations/
    ├── admin.py
    ├── apps.py
    ├── models.py
    ├── tests.py
    ├── views.py
    └── urls.py (create manually if needed)

----------------------------------------
4. REGISTER APP
----------------------------------------

Open:
    settings.py

Add the app to INSTALLED_APPS:

    INSTALLED_APPS = [
        ...
        'app_name',
    ]

----------------------------------------
5. RUN DEVELOPMENT SERVER
----------------------------------------

Default server:
    python manage.py runserver

Run on custom port:
    python manage.py runserver 5000

Run on custom host and port:
    python manage.py runserver 0.0.0.0:5000

----------------------------------------
6. DATABASE MIGRATIONS
----------------------------------------

Create migration files:
    python manage.py makemigrations

Apply migrations:
    python manage.py migrate

View migration status:
    python manage.py showmigrations

Create migrations for a specific app:
    python manage.py makemigrations app_name

----------------------------------------
7. DJANGO SHELL
----------------------------------------

Open Django shell:
    python manage.py shell

Exit shell:
    exit()

Example:

    from app_name.models import Student
    Student.objects.all()

----------------------------------------
8. CREATE SUPERUSER
----------------------------------------

Create admin user:
    python manage.py createsuperuser

Follow prompts:
    Username
    Email
    Password

----------------------------------------
9. ACCESS ADMIN PANEL
----------------------------------------

Start server:
    python manage.py runserver

Open browser:
    http://127.0.0.1:8000/admin

Login using superuser credentials.

----------------------------------------
10. COLLECT STATIC FILES
----------------------------------------

Collect static files:
    python manage.py collectstatic

----------------------------------------
11. USEFUL COMMANDS
----------------------------------------

Check project issues:
    python manage.py check

Display all available commands:
    python manage.py help

Show SQL for migrations:
    python manage.py sqlmigrate app_name migration_number

Flush database:
    python manage.py flush

----------------------------------------
12. CRUD OPERATIONS
----------------------------------------

Model Example:

    from django.db import models

    class Recipe(models.Model):
        title = models.CharField(max_length=100)
        description = models.TextField()

----------------------------------------
CREATE
----------------------------------------

    Recipe.objects.create(
        title="Pasta",
        description="Delicious pasta recipe"
    )

OR

    recipe = Recipe(
        title="Pasta",
        description="Delicious pasta recipe"
    )
    recipe.save()

----------------------------------------
READ
----------------------------------------

Get all records:
    Recipe.objects.all()

Get single record:
    Recipe.objects.get(id=1)

Filter records:
    Recipe.objects.filter(title="Pasta")

First record:
    Recipe.objects.first()

Last record:
    Recipe.objects.last()

----------------------------------------
UPDATE
----------------------------------------

    recipe = Recipe.objects.get(id=1)
    recipe.title = "White Sauce Pasta"
    recipe.save()

----------------------------------------
DELETE
----------------------------------------

Delete one record:

    recipe = Recipe.objects.get(id=1)
    recipe.delete()

Delete multiple records:

    Recipe.objects.filter(title="Pasta").delete()

Delete all records:

    Recipe.objects.all().delete()
